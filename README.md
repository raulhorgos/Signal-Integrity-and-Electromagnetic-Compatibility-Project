# Signal Integrity and Electromagnetic Compatibility Project

This project involves designing, routing, and validating a 5GT/s PCIe channel connecting an FPGA accelerator card to a server motherboard CPU.
The work-flow followed the next steps:

Pre-Layout: Defined routing constraints, via patterns, and impedance rules for 14-layer and 16-layer PCBs.

Layout: Routed the PCIe channel in CAD across the FPGA, edge connector, multiplexer, switch, and CPU.

Post-Layout: Verified signal integrity (eye diagrams, insertion loss, and jitter tolerance) against PCIsig compliance standards.
